## 言語 — このプロジェクトの上書き

グローバル `~/.claude/rules/language.md` は日本語を既定とするが、このプロジェクトでは
**GitHub が一次導線として表示する文は英語で書く**。書き手はセッション
（Codex へ委譲するときは委譲プロンプトで伝える）。

判定文: **GitHub がその文を一次導線として表示するか**——commit ログ・PR・Issue・Discussion・
Release notes・リポジトリのランディング（ルート `README.md`）。Yes なら英語。
リポジトリは公開されており、OrcaRouter の built-with 掲載を含め日本語話者以外の流入を
前提にするため、閲覧者が最初に当たる面だけを英語で揃える。

一次導線ではない（clone するか、ディレクトリを辿って初めて届く）ので日本語のままにするもの:

- ユーザーへの応答
- `docs/` 配下の spec / plan / designs — GitHub 上でレンダリングはされるが、
  リポジトリの導線からは辿られない設計記録である
- コード内コメント
- `README.ja.md`（ルートの `README.md` は英語が正）

**未決**: `skills/` 配下（`SKILL.md` と手法論 markdown）は上の判定文で決まらない。
MCP の Phase 3 でこれらが任意のクライアントへ配信されるようになるため、
**Phase 3 の plan を書く前に #57 で決める**。それまでは日本語のまま触らない。
